# Banners — Aulão de MMA, Striking e Grappling

Material de divulgação para o treino especial **com o Lennon**, sábado **19/09**, das **13h às 16h**.

A foto da turma foi só recortada para tirar a interface da galeria do celular. **Nenhum rosto foi alterado, gerado ou retocado.**

## Arquivos prontos para postar

Pasta `export/`:

| Arquivo | Formato | Uso |
| --- | --- | --- |
| `aulao-mma-stories.jpg` / `.png` | 1080×1920 (9:16) | Instagram Stories, WhatsApp Status, Reels cover |
| `aulao-mma-feed.jpg` / `.png` | 1080×1350 (4:5) | Feed do Instagram |
| `aulao-mma-quadrado.jpg` / `.png` | 1080×1080 (1:1) | Feed, WhatsApp, posts quadrados |
| `aulao-mma-horizontal.jpg` / `.png` | 1920×1080 (16:9) | Facebook, YouTube, banner de grupo, TV |

Prefira o **JPG** para enviar no WhatsApp e Instagram (arquivo menor). Use o **PNG** se for imprimir ou editar de novo.
